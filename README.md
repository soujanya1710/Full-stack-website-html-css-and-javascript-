Snake Game - Full Stack Python
A responsive Snake Game built with:
Python + Flask backend
HTML5
CSS3
JavaScript Canvas
SQLite database for high scores
Features
Score system
Increasing speed
Multiple levels
Game-over detection
High-score leaderboard
Restart button
Player name
Responsive mobile-friendly UI
How to run
1. Install Python
Install Python 3.10+.
2. Open terminal in this project folder
Install dependencies:
pip install -r requirements.txt
3. Start the server
python app.py
4. Open the game
Visit:
http://127.0.0.1:5000
On a phone, if the Flask server is running on another computer on the same Wi-Fi, use:
http://YOUR-COMPUTER-IP:5000
Game rules
Eat the red food to increase your score.
Every 5 points, the level increases.
Higher levels make the snake move faster.
Hitting the wall or yourself ends the game.
When the game ends, the score is saved to SQLite.
